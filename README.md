Technical Assessment 
Create a Svelte frontend in TypeScript and Spring Boot services in Kotlin with the 
following functionalities, 
1. List movies with artwork. 
2. Add, delete and update movies. 
3. Upload movie artwork. 
4. List cast and creators. 
5. Add, delete and update cast and creators. 
6. Search movies, cast and creators. 
7. Any functionalities that you think it should have. 
Requirements 
1. Should have at least 2 Spring Boot services. 
2. Service-to-service communication is via gRPC. 
3. Frontend to backend communication is via GraphQL. 
4. Include unit tests with complete test cases including edge cases. 
The web app should be responsive and provide sufficient feedback for the user to know 
the progress of the file upload, listing, updating and searching of data.
